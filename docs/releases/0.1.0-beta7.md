# PocketUFW 0.1.0-beta7 🐧

**Android 8.0+ · Root required · versionCode 29 · Experimental prerelease**

Beta 7 keeps PocketUFW's existing firewall policy while improving how Tide explains verified protection, reports gaps, and handles a few state-reporting edge cases.

## What's new

- **Clearer Tide status:** verified rules display a calm green **Active** headline. Expected carrier-network exclusions are explained in expandable **Coverage details** rather than repeated warning panels. An actual earlier Android/OEM ACCEPT bypass, uncovered non-carrier interface, or unknown coverage still produces a visible notice and actionable guidance.
- **Better Activity counters:** physical and tunnel sections now show matching **Return traffic** totals for established/related packets. PINNED tailnet-exempt packets remain separately counted, because they match an earlier rule.
- **Better diagnostics:** the Kernel rules view keeps a readable summary and horizontally scrollable raw rule view. Full coverage and interface limitations remain accessible.
- **Four focused reliability/security fixes:** detect reachable unhooked interfaces even when only link-local IPv6 or carrier is present; finish draining root/Insights output after child exit; tie Quick Settings cached status to boot identity; invalidate the cached tile state before firewall mutations.
- **Accurate boot documentation:** clarifies the one-shot restore behavior during unusually slow Android boots.

**Firewall policy unchanged:** PocketUFW's kernel filter engine, physical/tunnel DROP/ACCEPT policies, PINNED/DENY-ONLY rules, UDP exception policy, and boot scripts retain their Beta 6 behavior. Interface inventory, diagnostic reads, and UI/tile state reporting have changed.

## Validation

- Independent review of Tide's UI changes and an overall privileged-surface audit completed; four Low issues found in the broader review were addressed with targeted regressions that fail without the corresponding fix.
- **346 Android JVM/Robolectric tests and 683 Python tests passed.** The Python run had 21 skips requiring an Android mksh-specific build unavailable on the host. The Android release compiles, with zero lint errors and three pre-existing warnings.
- Isolated real-kernel tests cover unhooked link-local and addressless carrier interfaces, real dummy interfaces, rule ownership, lifecycle races, and tunnel behavior. These host tests do not prove every Android networking path.
- Signed with the same release certificate as Beta 6; all seven packaged firewall scripts were checked byte-for-byte against source.
- On a rooted **Pixel 9a / Android 17**, Beta 7 installed successfully in place over Beta 6 without wiping app data. Existing IPv4/IPv6 physical and tunnel hooks remained installed. The UI displayed verified ACTIVE protection, an earlier WireGuard ACCEPT rule, PINNED status, and a raw kernel-rule inspection. This is an initial device smoke test, not full hardware regression coverage.

## Limitations worth knowing

- **ACTIVE verifies PocketUFW's installed rules, not universal network coverage.** Earlier Android/OEM ACCEPT rules can bypass its hooks; carrier/IPsec traffic and some other interfaces may not be covered. The interface and earlier-rule inspection is a snapshot, not a continuous monitor.
- **PINNED grants address-based trust, not packet-origin authentication.** A separate `tun*` interface can potentially inject tailnet-source traffic to a pinned local destination. Optional tunnel filtering is not restored after reboot; physical boot restoration is a separate opt-in.
- **Insights is an on-demand diagnostic, not an intrusion detector.** Android/OEM rule changes can cause it to withhold a sample. Captures are bounded and do not identify apps or prove malicious intent.
- **Some real-device edge cases remain unverified:** app-level access to both boot identifiers, root-process completion after app termination, and certain Wi-Fi Aware/carrier/legacy-iptables and tunnel-injection scenarios.
- A **normal uninstall does not necessarily remove active kernel rules before reboot**. Use the in-app **Remove PocketUFW** flow first. The Magisk boot hook also has a documented slow-boot exception: if boot completion exceeds roughly 180 seconds, uninstall detection may be deferred to the next boot.

## Install and verify

Download the signed `PocketUFW-0.1.0-beta7.apk` and the accompanying `SHA256SUMS.txt`. The app ID is `io.github.pocketufw`, versionCode **29**.

Install it as an **in-place update** over a previous release signed with the same key; do **not** uninstall the active firewall just to upgrade. Recheck the protection and tunnel state after updating. In-place downgrades to older version codes may be rejected by Android.
