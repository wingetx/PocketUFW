# PocketUFW 0.1.0-beta8 🐧

**Android 8.0+ · Root required · versionCode 30 · Experimental prerelease**

**Prepublication candidate notes (the final UI polish is signed and installed privately; not yet published).** Beta8 is a usability and explanation release. The firewall policy, root-side engine, physical/tunnel rules, and Magisk boot scripts are unchanged from Beta7.

## What's new

- **Restore after reboot feedback:** the Settings switch displays immediate “Enabling…” / “Disabling…” progress, blocks duplicate taps, and reports the result only after verified readback; timeout and unverified outcomes remain visible.
- **Calmer, clearer firewall screen:** green **Active** means configured rules are verified, amber **Needs attention** identifies actual operational problems, and intentionally off is neutral **Inactive**. Normal coverage boundaries live within the expandable **Coverage details**, not a rotating orange banner.
- **Plain-language coverage:** the expanded disclosure separates what PocketUFW filters, what Android/VPNs handle independently, and when an action is needed. An optional technical section preserves interface names, earlier ACCEPT evidence, and precise PINNED trust limitations. The inbound status row now says **Filtered where supported** when verified.
- **Optional read-only Termux helper:** `pufw`, `pufw tunnel`, `pufw stats`, and `pufw raw` provide on-demand verified status/counters and diagnostics without starting a service or changing firewall rules. The collapsed **Termux quick commands** disclosure shows the commands, optional setup guidance, and tap-to-copy. The helper is prepared as a standalone release asset with a checksum and setup guide, **not automatically installed with the APK**. No source checkout is needed. See [Termux setup](../termux.md); the downloads become available when the release is published.
- **Quieter Settings footer:** a neutral experimental-beta note shows the actual app version. The redundant Quick Settings explanation was removed from Settings; the Android tile and its long-press behavior are unchanged. Automatic repair and background VPN monitoring remain unavailable, as described in [compatibility](../compatibility.md).

## Standalone Termux assets (publication preparation only)

From the repository root, choose a new output directory and run:

```sh
sh tools/package-termux android/build/termux-release
```

This copies the unchanged helper and setup guide, and generates its SHA-256
checksum. It does not build an APK, install, sign, or upload anything. It refuses
an existing output directory. The three planned release assets are **pufw**,
**pufw.sha256**, and **Termux-setup.md**; they are separate from the APK and source
archives. The checksum names only `pufw`, so verification works after download.

## Known compatibility limitation

**Confirmed on a Pixel 9a running Android 17:** with Wi-Fi calling active, PocketUFW can silently block incoming calls when the carrier's UDP 4500 conntrack entry expires during idle time. Calls were observed succeeding with PocketUFW disabled or the entry present, and failing with PocketUFW enabled and the entry absent. Users who rely on Wi-Fi calling to receive calls should **not enable PocketUFW's physical firewall** until this is addressed. Disabling Wi-Fi calling is a workaround only where cellular reception is reliable. Other phones/carriers and the effect on SMS were not tested.
